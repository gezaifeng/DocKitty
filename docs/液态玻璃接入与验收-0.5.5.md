# 稿喵 0.5.5：液态玻璃接入与验收

## 已接入

- 顶部主题菜单新增“液态玻璃”“液态玻璃 · 深色”，沿用已确认的玉绿、珍珠与桃色流动底板。主题不修改文档或项目数据。
- “功能”排在“文件”右侧，“使用帮助”位于顶栏最右侧；版本管理与项目管理共用开关。
- 全局功能包含关系图小组件、减少动态效果、减少透明度；玻璃主题另有背景流动、指针光效。
- 五种 Hairline 视效的右键菜单增加“关闭小组件”；从“功能”可重新打开并保留所选视效。选择与开关在下次启动时保留。
- 控件边缘高光、细磨砂纹理和透明填充共用主题材质。顶栏的磨砂层使用独立底板；弹出菜单独立模糊背后的文字，菜单自身文字不参与模糊。
- 指针事件直接更新光源，不使用位置缓动。坐标按边框与画布缩放换算；详情滚动不重复叠加滚动量。卡片或祖先移动时重新校准光源。旧位置的残光约 700ms 内渐隐。

## 使用

打开新版软件，在“主题”里选择“液态玻璃”或“液态玻璃 · 深色”。原有主题偏好保留，不会强制切换。需要更清楚的实色背景时，打开“功能 → 减少透明度”；需要静态界面时，打开“减少动态效果”，也可以单独关闭背景流动与指针光效。

本次只更新界面和界面偏好，未重置现有文档库、版本连接、分支或项目关系。没有操作真实论文文件夹，也没有重新发布 GitHub Release。
