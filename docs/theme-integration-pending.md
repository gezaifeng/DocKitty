## 1. 赤幕主题预览图跨主题空白

- 复现：当前主题为液态玻璃或其他非赤幕主题，打开主题选择器，赤幕色样显示白板；切到赤幕后色样正常。
- 当前源码证据：`ThemePicker.tsx` 始终渲染 `.wg-theme-swatch.redline`，但该色样的样式仅在 `redline.css` 的 `[data-theme=redline]` 下定义，还依赖赤幕专属 CSS 变量。
- 后续修复目标：主题预览色样独立于当前主题，任何主题下都显示同一红黑白图样；保持列表文字、焦点与选中反馈可读。
- 验收：全部主题分别打开选择器，检查赤幕色样的实际渲染，切换往返后仍正常。
- 已完成：赤幕色样使用独立色值，移除对当前主题和赤幕局部变量的依赖。`e2e/theme-bug-fixes.spec.ts` 在 12 个主题选项下检查同一渐变并留存截图。

## 2. 项目关系图连线穿过半透明卡片

- 复现：液态玻璃主题的项目关系图中，中心到中心的连线会从透明卡片内部显露，横穿标题或备注。
- 当前源码证据：`projectEdge.ts` 生成卡片中心之间的路径；`ProjectGraph.tsx` 将连线置于节点下层，但没有裁掉被节点覆盖的路径区段。
- 后续修复目标：只隐藏应被卡片遮挡的线段；卡片之外保留连线、箭头、标签及编辑交互，不移除关系、不改变端点和关系数据。
- 必须覆盖：起点／终点卡片、线条途中经过的其他卡片、拖动、缩放、方向反转、不同线型／宽度／箭头大小、所有主题。可见性裁剪还应处理命中区域，避免卡片覆盖区残留可点击连线。
- 实现方向待集成时验证：按当前节点几何边界裁剪或设置 SVG 遮罩，保留中心连接的逻辑。不能仅增加卡片不透明度来掩盖。
- 已完成：`ProjectGraph.tsx` 为所有当前层卡片生成 SVG 遮罩，覆盖边线、双实线间隙、箭头、标签与连线预览；透明命中屏蔽层阻止隐藏区响应边线鼠标操作。保持卡片透明度、关系数据和中心连接不变，遮罩随本地拖动位置即时更新。
- 已验证：浅、深色玻璃主题对实际桌面像素取样；有遮罩时卡片内部与隐藏整条连线时像素完全一致，去掉遮罩后复现穿线差异。另检查中间经过卡片、方向反转、双实线 / 虚线、宽度 / 箭头大小、拖动、缩放、卡片命中和 12 个主题切换。证据为 `docs/ak-ui-integration-audit/occlusion.json`。
