# 稿喵 0.3.2：版本、分类与量化功能接入

沿用已确认的BlockFrame和瘦长蓬松猫咪，补齐正式软件的功能入口与联动。运行 `dist/gaomiao-0.3.2-windows-x64/稿喵.exe`，需保留整个软件目录；旧0.3.1包保留。

## 版本与分类

- 总览历史、版本关系图、分类看板共享同一份文档及版本数据。
- 关系图支持分支查看、节点布局、分支指针调整、历史预览、继续编辑与双版本比较。
- 分类可创建、改名、删除，支持卡片拖拽、排序按钮及键盘移动；删除分类只将版本移回未分类。
- “查找版本”按名称、说明、作者、短版本ID或日期检索；可同时筛选分类，作用于历史列表、看板和关系图。
- 保存仍由用户自由选择覆盖当前版本或另存新版本；保留撤销覆盖、导出历史、恢复工作区、回收还原及备份流程。
- 被回收分支遇到同名冲突，可在设置页填写新的恢复名称。原有同名分支不被覆盖。
- Excel历史预览支持多工作表，并保留真实行号、列字母与公式提示；预览最多展开300个有效行、60个有效列。

## 量化指标与综合视图

共有55项逐版指标定义，按格式、上一稿是否存在及可解析数据动态出现。全部数值来自本地历史快照，缺失值不以零代替。

| 类别 | 指标 |
|---|---|
| 版本 | 文件体积、体积变化/增长率、覆盖修订次数、相邻记录间隔 |
| 文本 | 非空白字符、汉字、英文词、数字字符、中英混合字数 |
| 改动 | 新增、删除、总改动、净变化、保留率、修改强度、新增/删除占比 |
| Word | 段落、标题、章节区间、表格、绘图对象、脚注/尾注、批注总数与可识别状态；新增/删除段落、稳定标识下的改写/移动 |
| Excel | 工作表、有效行列、非空单元格、公式、错误值、有效行列交叉范围空值比例；工作表增删/改名、单元格新增/清空/改值、对齐行位置变化、公式增删/改写 |
| PPT | 幻灯片、备注字符、幻灯片文本增删/改写/换序 |

综合视图：保存活动（日/周/月）、首末时间与跨度、平均/中位记录间隔、分类/作者分布、相同二进制内容的额外版本数、大改排行、章节占比及逐版热区、结构变化明细、指定数值列的数量/合计/均值/极值、用户自设字数目标。

统计左侧选择分支与指标；展开“统计范围与基准”，指定基准、起止版本、日期范围及横轴。可选择对照分支查看共有/独有版本，并仅显示本路线独有版本。统计只读，不切换编辑分支。

点击图表或明细选择版本。“查看这份版本”返回历史预览；“与基准比较内容”打开已有双版本比较。CSV导出当前范围的全部逐版指标及基准差异；PNG导出当前趋势。导出位置须在文档库外，CSV文字已防止公式注入。

## 计数边界

- 中英混合字数=汉字+英文词，数字与标点不并入该指标；非空白字符数另计。与Word/WPS内置字数不保证一致。正文不包括页眉、页脚、脚注文字；脚注/尾注只报对象数量。
- 章节依靠标题样式及稳定段落标识/同名标题；无标识的标题重命名显示未匹配。段落没有稳定标识时改写表现为删除+新增，不推测语义对应关系。
- Excel优先匹配内容完全相同的唯一行，其余按工作表名称/标识及地址比较。插列、重复行、工作表重建等可能无法可靠对齐。公式表达式与缓存结果分别计数；数值列只汇总用户明确选定的列，不重新执行公式。
- 空值比例的分母是各工作表实际有内容的行与列的交叉格数；忽略纯格式化区域，不等同于整个最大矩形的空值比例。
- PPT变化仅指文本，不包含图片、排版或动画变化；备注字符来自备注XML文本。
- 首稿的相邻改动为不可用。逐字比较超过160000字符、120ms或20000编辑距离时停止；单版计数仍可用。结构明细最多显示80条，每条前后最多180字符，完整数量仍保留。
- 保存活动不表示实际编辑次数或时长；作者标签不是身份认证。覆盖记录缺少逐次发生时间，不能伪造活动历史。
- 旧DOC/XLS/PPT及无法解析格式仍能保存、恢复、导出版本并统计体积/记录时间；没有伪装为内容统计。PDF/OCR、实际Office排版页数、语义质量评分未接入。
