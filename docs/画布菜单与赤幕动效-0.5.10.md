# 稿喵 0.5.10 · 画布菜单与赤幕动效

## 本轮内容

赤幕原先只接入页面位移与淡入，未接入 HTML demo 的斜面遮罩。本轮补齐 260ms 斜面横扫，覆盖版本页面切换、项目视图切换和文件夹进入。遮罩仅作装饰，不拦截鼠标，也不变形关系图坐标。其他主题不增加横扫。

同时迁入菜单短促弹出、弹窗纸片入场、卡片错落出现和猫咪点击的摆动与星光。小猫悬停维持轻微旋转放大，不随机播放动作，也不出现选中底色。功能菜单和系统的减少动态效果设置均能关闭这些新增动效。

## 空白右键菜单

| 场景 | 操作 |
| --- | --- |
| 版本关系图 | 刷新工作目录与关系、导入文档／版本、新建文档、整理布局 |
| 项目文件关系图 | 刷新项目文件与关系、导入文件、导入文件夹、新建文档、新建文件夹 |

菜单沿用当前主题，依据实际尺寸靠近窗口边缘时自动避让，支持点击外部或 Esc 关闭、上下方向键选择。卡片与连线仍使用各自的原有菜单；右键拖线结束不弹出空白菜单。

版本刷新只扫描稿喵 `workspace` 根层的普通文件。新文件建立首个管理记录；已有文档不重复加入，已有编辑副本按原来的首次保存／后续覆盖规则同步。目录、链接、Office 锁文件与软件临时写入文件不作为新文档。历史、分支归属和最初论文来源文件不因扫描被重写。撤回扫描只撤回新管理记录，文件继续保留在工作目录。

项目刷新沿用原有项目刷新规则，读取关联来源并保留仍有效的手工关系；不会自动记录迭代。新建实际写入当前打开的普通文件夹，根层沿用项目工作目录或唯一来源目录，无法确定时由用户选择。历史快照与链接入口不接受新建。

新建文档支持 TXT、Word（DOCX）、Excel（XLSX）、Markdown（MD）。项目新建完成后显示当前卡片，同名不覆盖。新建动作与磁盘内容共同撤回／重做：已被外部修改的文件、非空文件夹或被占用的重做路径会阻止操作，不覆盖用户的新内容。

## 验证边界
