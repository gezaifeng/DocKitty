# 稿喵0.3.6：版本关系、卡片与测试隔离

交付目录：`dist/gaomiao-0.3.6-windows-x64`。关闭旧版后，运行整个目录中的 `稿喵.exe`。已复制现有文档与测试改动到新版测试库，原库保留；文档名称、版本、分支、分类与布局不自动清理。

## 右键管理版本

在关系图节点、分类看板卡片或历史列表上右键，新增以下操作：

| 操作 | 行为 |
| --- | --- |
| 删除版本… → 仅从版本管理中删除 | 隐藏版本并移入回收区；文件内容保留，可还原 |
| 删除版本… → 彻底删除该版本和文件 | 清除该版本在库内的正文和对应编辑副本，断开前后连接；不可从回收区还原 |
| 同时删除导入文件 | 在永久删除弹窗中显示完整路径；需主动勾选该选项和永久删除确认 |
| 修改分支归属 | 本稿从原分支移出，原前后连接断开；选择目标分支和前版本，或保持独立 |
| 断开与前版本的连接 | 删除所有进入本稿的连接线；正文及分支归属保留 |
| 断开与后版本的连接 | 删除所有离开本稿的连接线；后稿成为独立版本，不自动连到更早稿件 |
| 手动连接到前版本 | 添加“所选前稿 → 本稿”连接 |
| 手动连接到后版本 | 添加“本稿 → 所选后稿”连接 |

连接不要求与分支一一对应。同一分支可以有多个独立版本；手动连接也可跨分支选择来源。不能连接自己、形成循环或连接另一份文档的版本。新增连接会保留已有连接；需要更换单个前版本时，先断开再连接。

移动一稿的归属不等于将其全部后代移过去，正文不会重新保存。原前后稿件仍保留，断开的后代保留原归属。若移动的是分支末端，分支指向剩余稿件；若接到目标分支末端，目标指针前进到本稿。图中标签仍代表分支指向。

自由版本仍出现在该分支的列表、看板和量化统计中。统计按版本关系组织顺序；没有前版本时，新增/删除量为空，不假装与邻近时间的一稿存在修改关系。手动连接是整理关系的功能，软件保留原始快照，不改写正文。

## 永久删除边界

其他稿件仍使用的共享内容保留；若多个版本关联同一个导入文件，软件阻止一并删除该文件。永久删除移除库内专属文件内容、该稿编辑副本以及用户明确勾选的导入文件，不删除其他稿件。旧编辑会话关闭，再次保存不会自动复活版本。已导出的副本及以前的备份不受影响。

这里只支持删除实际单个文件，不递归删除导入目录，也不通过符号链接删除。目录型文档请先导出整理。最后一稿被删除后，文档记录可为空；仍可导入新的稿件。

## 当前测试库

新版目录内包含：

- `测试文档库.wg`：原文档库的独立复制品。
- `测试导入文件`：22份历史版本及附件的独立来源文件。
- `原文档库位置.json`：升级前的保存位置记录。
- `测试导入文件说明.json`：逐稿对应路径与校验值。

原论文目录里的路径仍可能出现在旧版本说明中，但这些说明不作为删除目标。已有历史的可删除来源全部指向测试文件夹。当前测试库设置了来源隔离，今后导入新稿也会生成内部测试来源；无论编辑、回收还是确认删除，都使用该测试副本。

普通正式文档库保留真实导入来源路径，用户必须在弹窗中核对路径并确认后，才会删除那份真实导入文件。来源隔离的内部路径能随备份恢复正确指向恢复后的库。

本轮准备测试库时，原论文目录的2765个现有文件前后校验一致。真实论文删除验证在额外临时复制品中进行，供用户试用的22份测试来源未被消耗或修改。

## 总览与小猫

文档总览改为自适应方框卡片，显示格式、名称、版本数量、当前分支、最近记录和状态；选择、双击进入关系图、搜索筛选、右侧预览与底部历史列表保持原有操作方式。长名称自动换行，小窗口改为单列。

左下角说明文字已移除，改为完整猫咪图片。右键可选择摸脑袋、顺毛、挠下巴，分别播放短动作；鼠标悬停只轻微旋转、放大，保持该姿态至鼠标移开，不播放互动动画；单击才播放摸脑袋互动。小猫自身始终透明底色，悬停、点击和鼠标焦点不出现绿色选定背景；键盘焦点保留描边。系统减少动态效果时只显示回应文字，不播放运动。

卡片、菜单、弹窗、猫咪周围的界面和文字使用同一套主题变量，覆盖BlockFrame、浅色办公、纸张书房、石墨暗色以及跟随系统。

## 单一分支归属与点选连接

每个版本只归属一个分支。筛选 TIP 时只显示 TIP 归属的稿件，main 祖先不混入；跨分支连接仍可以存在。卡片上方依次展示分支、分类标签，未分类不显示第二个标签。右键“手动连接到前版本/后版本”后，左键先点要调整的版本，再点前/后目标版本。页面提示当前步骤，可点击“取消连接”或按 Esc 退出；切换文档或视图也会退出。

本轮按最初导入清单恢复测试库：16 个论文历史版本与2份附件。当前测试库在切换前另存完整备份，新库来源均位于自身 imports 子目录，原论文文件未改动。已去除测试新增版本、分支、备注和手工连线；TIP格式稿归属TIP投稿，main保留中文与英文修订历史。

## 连接编辑保留位置

断开或连接时会保存整份文档的当前卡片坐标，独立版本仍保留原分支，不会因层级变化自动移位。右键画布空白处或版本卡可执行“整理布局”，统一恢复该文档默认排列，独立节点错开摆放；正文、备注、分支、分类与连线不变。新增位置保留、重启与防重叠验证后，核心107项、页面53项及软件本体定向测试通过。
