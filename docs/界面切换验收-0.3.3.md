# 稿喵 0.3.3：界面切换修复与验收

本轮针对实际使用中发现的导航遗漏，保留已经确认的品牌形象和主题，修复切换内容及按钮状态。0.3.2 的流程测试未覆盖空库视图切换、各文档类型的选中态，不能作为这些交互已经完成的证据。

## 修复

- 文稿、表格与数据、演示资料和全部文档共享选中状态；侧栏与格式下拉双向同步，列表标题、数量和空状态随筛选变化。
- 空库及未选文档时，版本关系图、分类看板、统计导航可以点击。每个页面有自己的说明、文档选择和空库导入/新建入口，不再停留在总览。
- 选中真实文档后仍进入真实关系图、分类看板或量化统计，不以示意数据冒充内容。
- 顶部视图、文档类型、回收内容、比较模式和设置入口均有明确状态；历史展开及统计指标补充可访问的状态标识。
- 统一按钮悬停、按下、键盘焦点和禁用状态；BlockFrame 导航选中态使用黑边框、硬投影和绿色色面。其他主题使用各自的主题变量。
- 关系图工具与说明使用主题边框、投影；筛选无匹配版本时显示独立反馈，避免只留下空画布。
- 逐指标测试复现了 Word 章节数量/章节变化、Excel 列数量/数值列统计的标识冲突。综合视图使用独立标识后，数量指标恢复自己的折线图与选中状态，不再误开综合视图。
- 切换统计指标或分支时，正文回到顶部，避免上一页的滚动位置把新页面标题和操作栏藏起来；左侧指标列表保持浏览位置。

## 验收范围

| 项目 | 实际检查 |
|---|---|
| 空库筛选 | 逐个点击全部、文稿、表格、演示；断言唯一选中、下拉值及标题同步，截图 |
| 下拉同步 | 下拉选择演示格式，断言侧栏演示按钮选中 |
| 空库视图 | 点击关系图、分类、统计；断言导航状态和对应页面标题、文档选择提示，截图 |
| 有文档筛选 | 软件创建 Word、Excel；逐类型检查列表数量，截图 |
| 导航状态 | 悬停与键盘焦点截图；BlockFrame 选中按钮断言2px边框及非空投影 |
| 真实页面 | 总览、关系图、分类、统计、设置、帮助、新建弹窗、文件及主题菜单截图 |
| 指标切换 | 遍历当前文档可用的所有指标和综合视图，断言唯一选中及内容标题变化 |
| 原有流程 | 导入、覆盖/新版本、分类、比较、备份、回收、统计范围/基准/导出等完整流程 |
| 主题一致性 | 四主题及跟随系统，在系统浅色/深色环境检查；正文无蓝色、无窗口横向溢出、无页面异常 |
| 小窗口 | BlockFrame 900×650截图 |

验收结果：96项桌面单元测试、类型检查和生产构建通过；正式包8项完整流程测试通过，主题矩阵生成222张截图。最后两行滚动位置修正后的正式包完整接入流程另外复测通过（`navigation-scroll-e2e.log`），逐项点击Word、Excel、PPT共92个指标/综合页面状态，并断言新标题处于窗口内。启动动画验证通过。

实际截图见 [主题与切换验收画廊](visual-audit/index.html) 及 [Word、Excel、PPT逐指标切换](indicator-audit/index.html)。正式包日志为 `visual-audit/navigation-final-e2e.log` 和 `navigation-scroll-e2e.log`，类型/构建/单元记录为 `navigation-typecheck.log`、`navigation-build.log`、`navigation-unit.log`。保留首轮 `navigation-e2e.log` 的启动等待失败和 `navigation-indicators.log` 的指标冲突失败，避免将先前的通过记录误当作最终版本的证据。
