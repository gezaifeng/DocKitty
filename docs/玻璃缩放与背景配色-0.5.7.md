# 稿喵 0.5.7：玻璃缩放与背景配色

## 处理

用户截图显示项目关系图在滚轮缩放期间出现画布下半部分的矩形渲染异常；用户进一步确认关闭背景流动后不再出现。此前静态背景的截图抽样没有复现这种动态异常，因此本次没有把静态截图通过等同于用户场景已经通过。

代码中缩放卡片包含背景滤镜，画布本身又叠加背景滤镜。现已将关系图磨砂处理移到固定视口的独立底板，缩放内容不再运行背景滤镜；卡片的透明填充、颗粒、高光和边框保留。版本关系图与项目关系图共用此处理。

另外，连续滚轮缩放会立即暂停流动背景的 SVG 形变与 CSS 运动，停止操作约 160ms 后从原位置恢复。保留用户的“背景流动”开关，不强制关闭；关闭状态和减少动态效果仍优先。此处理避免动态背景与缩放内容同时触发玻璃采样更新。

Chromium 对缩放变换与背景滤镜的交互曾有修复记录，作为本次排查参考：[缩放与背景滤镜修复](https://chromium.googlesource.com/chromium/src/+/63653a6b078897e39022b43d593047cbade93536)。这份记录不是对当前设备故障的唯一根因认定。

## 配色

“功能 → 背景配色”提供玉绿珍珠、蓝白、粉绿、黄黑、紫白、橙米。仅替换背景颜色；不改变排版、文字颜色、卡片几何与 SVG 动画路径。浅色和深色外观均支持，切换配色保留当前动画对象，退出重开后保留选择。

## 验证

- 主进程和界面类型检查通过，84 项界面单元测试通过。
- 两种关系图、两种玻璃外观的滚轮测试共抽样 80 帧；冻结背景的固定区域平均像素变化为 0，缩放内容内没有背景滤镜。开启流动时验证缩放暂停、停止后恢复；这些抽样不能证明所有显示驱动与每个中间帧都不存在闪烁。
- 六组配色在浅深两种外观的截图与交互测试通过，验证卡片位置及大小、文字颜色、SVG 对象保持一致，完整退出重新启动保留所选配色。
- 1,796 个实际窗口文字对比度抽样通过，最低约 4.69:1；包括不同背景动画位置。该抽样不代表对所有外部文档的全面无障碍认证。
- 测试使用独立临时库和新建文件，不修改真实论文或现有项目资料。

证据位于 `docs/glass-zoom-palette-audit/`：`zoom.json`、`palettes.json`、`materials.json` 及十二张配色截图。新安装包与打包后验证另见 `package.json`。
