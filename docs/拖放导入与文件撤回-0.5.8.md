# 稿喵 0.5.8：拖放导入与文件撤回

## 已确认的产品规则

1. 项目首页拖入文件夹，每个建立同名项目；散文件选择已有项目或新建项目。混合拖入先建立文件夹项目，再确认散文件；两步可分别撤回。
2. 项目内部拖到空白导入当前层，拖到文件夹卡片导入那个文件夹，文件浏览、关系图、分类看板均适用。
3. 外部资料逐项选择复制、剪切或保留原位置。当前普通文件夹优先作为目标，项目根层有唯一来源目录时使用它，多来源时由用户选择并记住工作目录。
4. 重名提供改名或跳过，建议带序号的新名称，不覆盖；当前层已有路径复用卡片。批量失败时回滚本批次已完成的磁盘操作与项目索引。
5. 版本管理空白位置默认新文档，拖到文档卡片或该文档的版本视图默认归入此文档，确认窗口可改为新文档。批量逐项设置归属，失败项可重试，已完成项不会重复处理。
6. 复制／剪切与导入卡片一起支持本次启动内的撤回与重做。回退前检查内容校验值、原位置和目标位置，外部改动或占用阻止操作；回退执行失败也恢复已经回退的步骤。

## 特殊情况

- 只接受磁盘文件或文件夹，网页生成的 File 对象没有原始磁盘路径时提示使用文件资源管理器。
- 不跟随链接复制其目标，链接卡片或含链接的目录只支持保留原位置。历史快照和链接卡片不能作为新增资料的目标。
- 检查真实路径，禁止导入自身文档库、复制目录到自身或子目录、通过目录联接绕过范围检查；目录后来改成链接时停止删除／回退。
- 手动确认剪切会移走真实来源；本轮所有验证均在独立临时目录进行，不操作真实论文或用户项目。
- 内部看板拖动只传递自己的卡片数据，不触发外部文件导入。取消、离开窗口或按 Esc 会清除拖放提示；原有视图、分类和连线操作保留。

## 验证与边界

新增 11 项数据测试验证文件夹建库、空目录、重名复制、目录剪切、真实文件撤回／重做、外部修改阻止回退、位置占用、批次失败回滚、模糊目标目录、同层去重、非法文件名、自身文档库和目录联接保护。

Electron 交互测试通过 Chromium 拖放协议注入真实磁盘文件，经过真实 File 对象、预加载路径转换、桌面 IPC 与磁盘操作；不伪造 File.path。覆盖两种入口、指定文档和文件夹、复制取消与重名、剪切与快捷键回退、项目首页卡片、多来源目标选择、关系图与看板卡片、历史快照拒绝、九主题及小窗口。目录选择测试使用受控的原生文件选择器返回值，不等同于操作系统文件选择器的手工验收，也不声称完成资源管理器窗口的鼠标拖动验收。

路径转换参考 [Electron 官方 webUtils](https://www.electronjs.org/docs/latest/api/web-utils)。仅用于读取本地拖入对象的路径，不将文件系统 API 开放给网页预览。

验收产物位于 `docs/file-drop-audit/`：`interaction.json`、`edge-cases.json`、`themes.json` 及截图。最终软件入口和安装包核对记录另见该目录的 `package.json`。安装包生成不等同于重新执行安装向导；不同设备权限、被办公软件占用的文件和真实跨磁盘速度仍依目标环境而异。
