# 稿喵 0.3.0：BlockFrame 与真实版本统计

此页保留0.3.0的历史范围。当前0.3.2已补齐基准、统计范围、导出、章节热区、结构变化及数值列等入口；以 [当前功能接入说明](功能接入-0.3.2.md) 为准。品牌与动效以 [当前品牌说明](brand-lab/README.md) 为准。

2026-10-11。此轮已从独立演示接入软件本体，所有统计数值来自本地历史快照。

## 使用入口

在总览选中文档，点击顶栏“版本统计”。分支选择固定在左侧，下面按版本、文本、改动及文档类型分组列出指标。每个指标按钮从左向右错落入场；切换指标后右侧数字卡、曲线、详情与明细按45ms间隔依次出现。尊重系统减少动态效果。

统计只改变查看范围，不切换编辑分支、不写工作区。版本路线沿分支头的第一父版本追溯，包含共同祖先，不计回收节点。多父版本只取第一父主线，不把多个路线按时间混排。

## 已接入指标

- 版本：文件大小、保留的覆盖修订次数、路线版本数、保存日期活动。
- 文本：正文非空白字符数、汉字数、英文词数。
- 相邻改动：新增字符、删除字符、总改动、净变化、文本保留率。
- DOCX：段落数、表格数、绘图对象数、批注总数。批注总数不等于未解决批注数。
- XLSX：工作表数、非空单元格数、公式数、错误值单元格数。
- PPTX：幻灯片数、备注字符数及幻灯片正文文本统计。
- TXT/MD/CSV/JSON/XML/HTML：UTF-8源文本统计；HTML/XML按源文本计数，不声称是渲染后正文。

指标按实际格式和可解析数据出现。首稿无上一稿，增删量不伪造为0。解析失败只保留文件大小与版本记录，缺失指标显示“—”，曲线断开。旧DOC/XLS/PPT不声称已支持内容统计。

为避免大改稿件阻塞，超过160000总字符或差异计算超过120ms/20000编辑距离时，不计算相邻逐字差异；单版计数仍可用。正文计数去空白、按Unicode码点计算，英文词另列；不同于Office内置字数。DOCX不包含页眉页脚、脚注等其他部件；PPT备注按备注文本部件提取。

历史内容的解析缓存以仓库、文档名、内容ID区分，最多保留256个结果。覆盖同版本更换内容ID，重新统计但不新增节点。每次路线刷新都读取当前版本元数据，覆盖次数与回收状态不会因缓存丢失更新。

## 视觉与品牌

BlockFrame作为新默认主题，保留原主题切换入口。已有UI偏好升级时迁移到BlockFrame，文档库配置不改变。粗黑边框、黑色硬投影、浅黄导航、浅绿统计卡和中性文字覆盖工作台、关系图、看板、对话框与统计页。

完整二维猫咪通过imagegen重新生成，粗黑线、奶油/杏色/鼠尾草色块及文档胸牌与软件统一。原图和提示词见[生成记录](brand-lab/blockframe-cat-prompt.md)。整张PNG用于0.92秒到位、缓冲与回弹，手和尾巴不拆分；加载完成后从胸牌位置440ms展开真实页面。任务栏、EXE和应用内PNG/ICO同步更新。

启动离线入口：[BlockFrame开场预览](brand-lab/startup-blockframe-preview.html)。正式包：`dist/gaomiao-0.3.0-windows-x64/稿喵.exe`，运行时应保留同目录资源。
