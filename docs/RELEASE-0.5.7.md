# 稿喵 0.5.7 · 项目资料与液态玻璃

同一款软件，两个工作入口：保存单份稿件的修改历史，也整理整个项目的文件、文件夹与迭代关系。

## 新增项目管理

- 左上角切换版本管理 / 项目管理；批量导入文件，或把整轮文件夹作为一张卡片。
- 按当前文件夹层级浏览，跨文件夹关系在详情中跳转；支持文件类型筛选。
- 文件与文件夹均可拉出带方向的关系线，标签与备注自由填写；分类看板在当前层展示，分类名称全项目共用。
- 来源修改后刷新当前内容，明确“记录下一轮”才创建历史节点；提供展开预览及 Codex、Claude Code、Cursor、DSH 的 MCP 配置入口。

## 九种外观与六组玻璃配色

- BlockFrame 黑框积木、粉绿方块、经典视窗、胶囊文具、浅色办公、纸张书房、石墨暗色，以及浅色 / 深色液态玻璃；另支持跟随系统。
- 液态玻璃包含流动背景、磨砂颗粒、边缘高光和即时指针光迹；功能菜单提供玉绿珍珠、蓝白、粉绿、黄黑、紫白、橙米六组背景配色。
- 保存用户的主题、配色与全局效果选择；小组件可关闭及重新开启。
- 调整玻璃渲染层级：关系图缩放时背景短暂停顿，停止约 160ms 后恢复流动，减少动态背景与缩放叠加的渲染冲突。

## 操作完善

- 左键选中卡片后右键拖到另一张卡片连线；双击 / 右键连线打开同一个可拖动编辑面板。
- 箭头形状、大小、线型和粗细实时预览；反转版本箭头交换前后连接并阻止循环。
- 文件菜单恢复原功能并增加撤回 / 重做及快捷键；提示约 2.5 秒后自动消失。
- README 用 v0.5.7 实际程序的虚构资料截图展示文档历史、项目管理、主题与配色。

## 安装

下载 **DocKitty-Setup-0.5.7-x64.exe**，双击安装，从桌面或开始菜单打开“稿喵”。支持 Windows 10 / 11 x64，已包含运行环境，无需 Node.js、Python、pnpm 或 Git；编辑办公文档仍需要已有 Word、WPS、Excel 或其他关联程序。

软件尚未签名，Windows 可能显示未知发布者提示。项目管理的“编辑原文件”会打开真实导入来源，刷新遵循来源删除 / 改名规则；重要文件请保留独立备份。安装包不包含作者论文、个人文档库或账户凭据。

## 验证范围

- 144 项核心测试、50 项桌面后台测试、84 项界面测试通过。
- 标准 MCP 客户端实际 stdio 工具测试通过；本轮专用 DSH 端到端测试未启用，不将其算作已通过。
- 打包后的版本关系图 / 项目关系图、浅深玻璃、六组配色与退出重启保存已验证；安装包校验值随附件提供，本轮未重新执行安装向导。
- 玻璃缩放固定区域共抽样 80 帧，文字对比度共抽样 1,796 次；这些检查不代表所有显卡和文档格式都已覆盖。
