## 两项修复

1. **赤幕色样空白**：色样定义从 `[data-theme=redline]` 中移出，使用独立红黑白色值。切换到任意主题仍可看到赤幕的正确预览。
2. **项目线条穿过半透明卡片**：对所有当前层卡片生成与卡片位置、尺寸、圆角一致的 SVG 遮罩，隐藏卡片所覆盖的线段，包括途中经过的第三张卡片。附加透明命中屏蔽层，防止 SVG 遮罩虽然隐藏像素却留下鼠标命中区。保持原始关系和卡片透明度，不改变其他主题的资料数据。每次拖动与缩放使用同一坐标系即时更新。
