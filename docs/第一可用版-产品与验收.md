# word_git 第一可用版：统一工作台与版本操作

目标：一个本地仓库、一份文档一条记录、同一份版本数据供总览 / 关系图 / 分类看板使用。视图只是查看方式，切换视图不能复制、遗漏或改写版本。

## 产品规则

1. 总览管理“文档”，不是文件名相似的副本列表。导入时明确选择“新文档”或“选中文档的新旧版本”，不同文件名的同稿归入同一文档。
2. 用户可在保存时选择“覆盖当前版本”或“另存新版本”。覆盖不增加可见版本节点，三个视图都指向更新后的内容；底层保留替换记录以便撤销。展示名称、说明、分类和位置可直接编辑。
3. 关系图表达真实父子关系与分支。拖动节点保存位置；拖动分支标签到版本节点，通过确认改变该分支的起点，并为原路线保留保护分支。点击分支最新稿可在该路线继续编辑并打开系统编辑器。第一版不提供自动内容合并。
4. 看板分类是文档内可增删改的自定义栏目，与分支独立。移动卡片不切换工作区；删除栏目把卡片退回“未分类”，不删除版本。
5. 文档和版本删除进入回收视图；版本仍保存于对象库并可还原。删除旧祖先不重写后代的真实父关系。默认隐藏删除项，可查看回收内容。
6. 当前工作区是编辑副本，历史预览和导出均只读。直接打开当前工作区、继续编辑同一最新稿时不重复检出；从其他稿件编辑或恢复 / 切换前自动保护有变化的工作区为一个版本，任何错误必须显示在界面。
7. 总览、关系图、看板共用仓库和文档选择状态；编辑分类、说明、布局或删除后更新所有相关查询，重启从磁盘恢复。
8. 三种统一主题（浅色办公 / 纸张书房 / 石墨暗色）只改变设计令牌，不改变信息结构或业务数据；在菜单中切换。
9. 所有操作提供可点击入口：创建文档、导入文档/版本、保存工作区、从旧稿编辑、比较、导出、建/切/删分支、分类 CRUD、版本整理和回收恢复。
10. 新建支持最常用的 Word、Excel、文本；其他格式通过现有模板文件导入。保持系统 Office/WPS 编辑，不开发内嵌文档编辑器。

## 实施与验证顺序

- 数据层：可读旧仓库，保真存储、工作区保护、统一分类与版本元数据 → 临时真实文件回归，重启与备份往返。
- IPC：共享校验契约、序列化写入、全分支唯一版本查询、导入和导出 → 真实 handler 集成测试。
- UI：总览作为入口，选中稿后图谱和看板联动；一致主题与反馈 → 浏览器组件测试及运行截图。
- 交付：可运行桌面、可用操作流程、使用教程与启动方式 → 真实 Electron E2E、生产构建、打包运行。
