# Third-party notices

DocKitty bundles Electron and its Chromium/Node runtime. Their license texts are included in the application directory as LICENSE and LICENSES.chromium.html.

The five interactive Hairline figures by Lucas Markes use the MIT license; see Hairline-LICENSE.txt in the installer directory and the source license at apps/desktop/src/renderer/src/vendor/hairline/LICENSE.

The MCP server bundles the official Model Context Protocol TypeScript SDK (Apache-2.0), Zod (MIT), and the Node HTTP adapter with its dependencies. Package versions and license texts are included under MCP/licenses. The SDK's distributed modules may themselves include vendored dependencies and retain their upstream attribution comments.

The source repository lists all other application dependencies and exact resolved versions in package.json files and pnpm-lock.yaml. The visual themes use local CSS; no remote UI service is needed to run the software.
